# 复现环境

## Python

- Python 3.11或更高版本
- 安装命令：`python3 -m pip install -r requirements.txt`
- 依赖范围见仓库根目录`requirements.txt`。

## R

- R 4.3或更高版本
- 安装命令：`install.packages(c("ggplot2", "dplyr", "tidyr", "patchwork", "scales", "ragg", "svglite", "systemfonts"))`
- 本次冻结环境中的包版本记录在`R依赖.txt`。

## 字体

论文冻结图使用`Microsoft YaHei`和`Helvetica`。可用`HYDRO_ZH_FONT`和`HYDRO_LATIN_FONT`替换，例如：

```bash
HYDRO_ZH_FONT="PingFang SC" zsh reproduce.sh formal
```

字体替换可能改变图件中文字宽度和PDF/SVG文件字节，因此若需逐像素核对论文冻结图，应使用相同字体；统计结果表不受字体影响。
