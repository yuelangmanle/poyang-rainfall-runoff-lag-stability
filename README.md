# Rainfall–Runoff Lag and Stability across Seven Poyang Lake Basins

仓库名称：**poyang-rainfall-runoff-lag-stability**

论文题名：**鄱阳湖七流域降水径流相关滞后及稳定性**

本仓库用于公开复现数据覆盖期为 2006—2020 年、主分析期为 2006—2019 年的鄱阳湖七个典型子流域降水—径流相关滞后、季节差异与稳定性分析；2020 年仅用于敏感性场景。仓库收录可公开分发的标准化数据、数据审计表、正式分析表、正式分析 5 幅图及论文最终 4 幅图，并提供从来源数据开始的完整复现入口和低重复次数的快速检查入口。

## 仓库内容

- **01_数据/处理后数据/**：七流域 2006—2020 年日尺度标准化数据及其校验值；正式主分析使用 2006—2019 年。
- **02_分析代码/**：下载与校验、数据审计与标准化、正式分析、绘图和结果验证脚本。
- **03_分析结果/表/**：原始数据结构、字段、换算公式、极端值和重复序列的审计表。
- **03_分析结果/正式分析/**：正式参数、结果表、5 幅正式分析图、运行摘要及核心产物哈希清单。
- **03_分析结果/投稿级图预览/结构重构版/**：论文最终 4 幅图的 PNG、PDF 和 SVG 导出。
- **环境/**：复现所需的软件环境与依赖约定。
- **checksums/**：公开分发文件和冻结产物的清单与校验信息。
- **reproduce.sh**：统一的正式复现与快速检查入口。

## 开始之前

1. 在仓库根目录运行命令。
2. 按 **环境/** 中的依赖说明准备 Python 与 R 环境。
3. 保持网络可访问 Mendeley Data，以便脚本从官方来源取得原始 Excel。
4. 原始 Excel 仅作为本地复现输入，不属于本仓库的分发内容，也不应加入版本控制。
5. 论文冻结图使用 `Microsoft YaHei` 和 `Helvetica`。如系统没有该中文字体，可在命令前设置 `HYDRO_ZH_FONT` 为本机已安装且覆盖中文字符的字体，例如 macOS 的 `PingFang SC` 或 Linux 常见的 `Noto Sans CJK SC`。替换字体可能改变 PDF/SVG 字节与文字度量，但不改变统计数据。

## 正式复现

执行：

    zsh reproduce.sh formal

正式模式从 Mendeley Data 来源文件开始，依次执行下载与校验、数据审计与标准化、正式参数分析、绘图和产物验证。该模式使用论文正式分析参数，并将核心产物与仓库中的冻结 manifest 对照。若来源文件校验、分析步骤或冻结产物比对失败，运行应以非零状态结束；不要将失败运行解释为成功复现。

正式模式用于核对论文所报告的数值、表格和图件。运行前如有本地修改，应先自行保存，以便区分复现产物与已有文件。

## 快速复现

执行：

    zsh reproduce.sh smoke

快速模式在临时目录中从 Mendeley Data 下载数据，完成数据校验与审计、低重复次数分析并生成5幅基础分析图，然后自动清理临时目录。该模式不重画带有正式统计断言的论文最终4幅组图，也不修改仓库收录的冻结产物，适合检查依赖、数据接口和端到端执行路径。

快速模式为降低等待时间而减少重复次数，其数值波动和不确定性估计不能替代正式模式，也不应用作论文结论的数值依据。

## 数据与解释边界

- 处理后数据是为本研究分析目的生成的派生数据，不能替代原始数据的来源记录；原始字段、单位换算、缺失值、极端值和重复序列处理应结合审计表与脚本解释。
- “最佳滞后”表示给定时间分辨率、候选滞后范围和相关分析定义下的统计峰位，不等同于水体的物理传播时间，也不能单独证明降水对径流的因果作用。
- Bootstrap 区间、最佳滞后概率和敏感性分析描述的是本仓库所实现方法下的不确定性与稳定性，不消除观测误差、数据代表性或模型设定带来的限制。
- 跨流域与季节比较只适用于本研究的数据范围、空间对象和方法设定；向其他年份、流域或时间尺度外推时需要重新验证。
- 快速模式只验证复现链路，不验证正式重复次数下的数值一致性。论文数值应以正式模式及冻结产物核对结果为准。
